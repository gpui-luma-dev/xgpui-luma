Resizable Panels

look-shadcnlook-radix

Panels separated by draggable handles.

Basic use

Radix · integration snippet
use xgpui_luma_look_radix as radix;
use gpui::{Context};
use gpui::{div, prelude::*};
use xgpui_luma::controls::resizable_panels::ResizablePanelSpec;

struct Example {
    control: gpui::Entity<xgpui_luma::controls::resizable_panels::ResizablePanels>,
    panel_sizes: Vec<f32>,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let look = radix::Look::built_in();
        let control = radix::resizable_panels_builder(&look, "workspace")
            .panels([
                ResizablePanelSpec::new_render(|| div().child("Navigation")),
                ResizablePanelSpec::new_render(|| div().child("Content")),
            ])
            .on_resize_end(cx, |app, sizes_px, cx| {
                app.panel_sizes = sizes_px.clone();
                cx.notify();
            })
            .spawn(cx);

        Self { control, panel_sizes: Vec::new() }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

Radix styling

resizable_panels_builder(&look, id) installs Radix frame, divider, grip, and disabled styling. SDK constraints, panel identities, hide/restore, collapse, keyboard resizing, and motion remain available. resizable_panels_theme and resizable_panels_template support manual composition.

Pass an explicit Look, including forks. Theme adapters retain that binding; notify affected controls and their owners after palette, mode, or stylesheet edits. Resolved look values are snapshots and must be resolved again during render.

See the Radix control support table for adapter and utility status.

SDK behavior & customization

Configure sizes, constraints, and collapse behavior. Panel identity is independent of physical index.

Relevant contracts: ResizablePanelsRenderModel, ResizablePanelsTemplateModifier, ResizablePanelsTemplate, ThemedResizablePanelsTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
ResizeStart.on_resize_start(cx, |app, cx| { … })
SizesChanged { sizes_px: Vec<f32> }.on_sizes_changed(cx, |app, sizes_px, cx| { … })
ResizeEnd { sizes_px: Vec<f32> }.on_resize_end(cx, |app, sizes_px, cx| { … })
PanelHiddenChanged { panel_index: usize, hidden: bool }.on_panel_hidden_changed(cx, |app, panel_index, hidden, cx| { … })
PanelRegionHiddenChanged { region: PanelId, panel_index: usize, hidden: bool }.on_panel_region_hidden_changed(cx, |app, region, panel_index, hidden, cx| { … })
HandleFocusChanged { handle_index: usize, focused: bool }.on_handle_focus_changed(cx, |app, handle_index, focused, cx| { … })
HandleHoverChanged { handle_index: usize, hovered: bool }.on_handle_hover_changed(cx, |app, handle_index, hovered, cx| { … })
EnabledChanged { enabled: bool }.on_enabled_changed(cx, |app, enabled, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through ResizablePanelsEventExt. Existing cx.subscribe observers remain supported.
