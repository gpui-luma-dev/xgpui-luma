Design notes (not part of the screen)

  • Slots: hero = one stage pane (heading + badges over a card surface), cards = the four samples, wide panel = Motion, narrow panel = Logical layer, note = Try it, fine print = accessibility and scope.
  • Removed: the "TYPE / 04" eyebrow, the "Bright ideas. Real words." display line, the issue number in the breadcrumb, and the 1040 px column. The title is the screen name.
  • Buttons become controls: sample buttons with ✓ become selectable cards; the motion buttons become a Motion selector; "Width / Type / Reduced motion: on/off" text buttons become switches; "Sample colors: ink/light" is dropped because the sample gradient follows the look's mode.
  • Selection actions (Select all, Copy) sit on the Logical layer panel, next to what they act on, so the control row holds only settings.
  • Transport (Play/Pause, Restart, ±10%, New seed, Next frame) lives with the motion parameters, not in the control row. Seed and frame rows apply to Scramble (and frame to Wave); disabled otherwise.
  • Values in mono (IBM Plex Mono, the look's code style): field values, scalars/bytes, range, selection and source in the logical layer.
